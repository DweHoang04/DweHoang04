### 🔬 Research & Key Projects

| Project / Affiliation | Core Focus | Methods & Tech Stack |
| :--- | :--- | :--- |
| **Anti-vibration Control of Elastic Single Mast Stacker Crane**<br>*(MoCAR LAB – WSR Group, HUST)* | Suppressing mast vibrations for time-varying robotic systems. | • **Model:** Euler-Bernoulli beam theory & Hamiltonian method<br>• **Control:** Active Disturbance Rejection Control (ADRC) + Modified Input Shaping (IS)<br>• **Stack:** `MATLAB/Simulink` `NI myRIO` `LabVIEW` `Mitsubishi Servos` |
